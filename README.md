# ⚡ EV Charging Station Management System

## 📌 Project Overview

The **EV Charging Station Management System** is a database-driven project designed to manage and analyze electric vehicle charging operations.

The project focuses on managing customers, vehicles, charging stations, charging ports, bookings, charging sessions, payments, and maintenance activities.

It uses **Oracle SQL** for database management and querying, and **Power BI** for data visualization and business intelligence.

The primary goal is to transform operational data into meaningful business insights that help EV charging companies improve operational efficiency, monitor station performance, understand customer behavior, and make data-driven decisions.

---

## 🎯 Business Objectives

- Manage customer and vehicle information.
- Monitor charging station and charging port operations.
- Track charging bookings and sessions.
- Analyze energy consumption and payment transactions.
- Monitor station maintenance and operational issues.
- Identify high-performing and underperforming charging stations.
- Generate actionable insights for business decision-making.

## 🗄️ Database Design

The database consists of **8 tables**, designed to manage different aspects of EV charging operations.

| Table Name | Description |
|---|---|
| CUSTOMERS | Stores customer information |
| VEHICLES | Maintains customer vehicle details |
| CHARGING_STATION | Stores charging station information |
| CHARGING_PORTS | Maintains charging port details and availability |
| BOOKINGS | Stores customer charging reservations |
| CHARGING_SESSION | Tracks actual charging activities and energy consumption |
| PAYMENT_TABLE | Maintains payment transaction details |
| MAINTENANCE | Tracks station maintenance and repair activities |

### Database Relationships

The database uses primary keys and foreign keys to establish relationships between the tables and maintain referential integrity.

## 📊 Project Modules

1. **Customer Management** – Manage customer information.
2. **Vehicle Management** – Maintain registered EV details.
3. **Charging Station Management** – Manage station information and locations.
4. **Charging Port Management** – Monitor port availability and operational status.
5. **Booking Management** – Manage charging reservations and cancellations.
6. **Charging Session Tracking** – Track charging duration and energy consumption.
7. **Payment Management** – Monitor payment transactions and payment status.
8. **Maintenance Management** – Track maintenance activities and resolution status.

## 📈 SQL Business Analysis

The project includes business-oriented SQL queries designed to solve real-world problems faced by EV charging operators.

Some of the analytical questions include:

- Which charging stations have the highest charging demand?
- Which customers have unusually high booking cancellation rates?
- Which vehicles consume the most charging energy?
- Which charging stations generate the highest revenue per session?
- Which charging port types generate the most revenue?
- Which stations experience frequent maintenance incidents?
- Which stations require additional charging infrastructure?
- Which customers show significant growth in monthly energy consumption?
- Which stations experience declining monthly revenue?
- Which customers contribute the highest lifetime revenue?

### SQL Concepts Used

- Joins (INNER JOIN, LEFT JOIN)
- Aggregate Functions
- GROUP BY and HAVING
- Subqueries
- Common Table Expressions (CTEs)
- CASE Expressions
- Analytical Functions (LAG, DENSE_RANK)
- Date Functions
- Conditional Aggregation
